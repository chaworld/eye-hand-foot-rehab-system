# 暖身運動復健系統使用說明

**支援的暖身運動:**
- **站姿抬膝** — 鍛鍊核心肌群和髖部活動度
- **髖部畫圈** — 增進髖關節靈活性和穩定度

---

## 快速開始
### 方式 1: 從主選單啟動

1. 開啟終端機，進入專案目錄:
   ```bash
   cd D:\python_code\eye_hand_foot
   python app.py
   ```

2. 在彈出的應用程式視窗中，點擊 **「暖身運動復健系統」** 按鈕

3. 瀏覽器會自動開啟訓練頁面 (http://localhost:5000)

### 方式 2: 直接啟動訓練模組
如果想直接進入訓練頁面，無需經過主選單:

```bash
cd D:\python_code\eye_hand_foot
python warmup_rehab\server.py
```

瀏覽器會自動開啟 http://localhost:5000

## 操作步驟

### 第一步: 選擇運動

頁面上方有兩張運動卡片:

- **01 站姿抬膝** (STANDING KNEE RAISE)
  - 單手扶持固定物，將膝蓋向上抬起靠近胸口，雙腿交替進行
  
- **02 髖部畫圈** (HIP CIRCLE MOVEMENT)
  - 模擬跨越障礙物，大腿抬高後向外打開，再循原軌跡收回

點擊任一卡片即可選擇該運動。選中的卡片會以深色邊框突顯。

### 第二步: 設定目標次數

在頁面下方「CONTROLS」區塊，有一個輸入框用於設定 **TARGET REPS** (目標次數)。

- 預設值為 **10 次**
- 可調整範圍: 1 ~ 30 次
- 根據您的體力和訓練計畫自由調整

### 第三步: 啟動訓練

1. 確保攝影機已連接並且沒有被其他應用程式占用
2. 點擊 **「START」** 按鈕開始訓練
3. 系統會啟動攝影機，顯示即時影像
4. 頁面上的各項數據會開始更新:
   - **REPETITIONS** — 已完成的次數
   - **ELEVATION** — 目前大腿的抬起角度 (單位: 度)
   - **QUALITY** — 動作品質評級 (poor / good / excellent)

### 第四步: 訓練進行中

在訓練過程中，系統會提供多種回饋:

#### 即時視訊反饋
- **骨架圖** — 顯示您的身體關鍵點和連接線
  - 綠色骨架: 腳部 (訓練中無關但會顯示)
  - 灰色骨架: 腿部連接
  - 各色圓點: 關節位置

#### 動作進度指標
- **ACTIVE SIDE** — 顯示目前正在訓練的腿部 (L = 左, R = 右)
- **CURRENT PHASE** — 當前動作階段
  - 站姿抬膝: ready → lifting → peak → lowering
  - 髖部畫圈: ready → lift → rotate → descend
  - 當前階段會以實心圓點標示，已完成階段為灰色

#### 姿勢反饋 (FORM FEEDBACK)
系統會即時偵測您的姿勢，並在發現問題時提示:

**站姿抬膝的常見提示:**
- 「身體不要前傾」 — 您的軀幹向前傾斜，應該保持脊椎中立
- 「再抬高一點」 — 膝蓋的抬起高度不足，目標是與腰部齊高
- 「動作太慢，請加快」 — 抬腿的速度過慢

**髖部畫圈的常見提示:**
- 「身體不要前傾」 — 同上，保持軀幹穩定
- 「大腿再抬高」 — 大腿高度應平行地面
- 「再往外打開」 — 向外展開的幅度不足，目標約 70 度
- 「腳趾用力抓地」 — 提醒您強化足底肌群的支撐力

**顏色提示:**
- 綠色邊框 + 黑色文字 = 姿勢正確，無警告
- 紅色邊框 + 紅色文字 = 檢測到姿勢問題，需要改進

#### 語音指導 (可選)
系統會透過揚聲器播放語音提示，幫助您更好地理解訓練指導。可在系統音量設定中調整。

### 第五步: 完成訓練

當您完成目標次數的訓練時:

1. 頁面會自動顯示 **「SESSION COMPLETE」** 結果彙總
2. 訓練統計包括:
   - **TOTAL REPS** — 完成的總次數
   - **SECONDS** — 訓練持續時間
   - **FORM %** — 姿勢合規率 (百分比)
     - 衡量您在訓練期間保持正確姿勢的比例
     - 高合規率意味著動作執行得更規範

3. 點擊 **「CLOSE」** 按鈕關閉結果彙總，可選擇進行下一次訓練

### 中途停止訓練

如果需要在完成目標次數前停止訓練，點擊 **「STOP」** 按鈕即可。系統會:
- 停止攝影機和動作偵測
- 記錄當前進度到訓練紀錄
- 顯示中途停止時的成績統計

## 常見問題

### Q: 攝影機無法連接
**A:** 
- 檢查攝影機是否正確連接到電腦
- 確認沒有其他應用程式正在使用攝影機 (如視訊會議軟體)
- 重新啟動訓練系統

### Q: 姿勢偵測不準確
**A:**
- 確保光線充足，攝影機能清楚看到您的身體
- 穿著顏色與背景有對比的衣服，有助於更好的偵測
- 攝影機應距您約 1.5 ~ 2 公尺
- 確保身體全部可見，特別是頭部、肩膀和腿部

### Q: 為什麼我的動作被系統記為「poor」品質
**A:**
- **站姿抬膝:** 膝蓋抬起高度未達 45 度，或軀幹有向前傾斜
- **髖部畫圈:** 大腿高度或外展角度不足，或整體動作執行不完整

改進建議:
- 放慢速度，注重動作的完整性而非速度
- 在鏡子前檢查您的姿勢，確保脊椎保持中立
- 加強核心肌群力量，幫助保持穩定

### Q: 訓練紀錄存在哪裡
**A:**
所有訓練紀錄會自動存檔至:
```
D:\python_code\eye_hand_foot\logs\training_sessions.csv
```

每次訓練結束後，系統會新增一列記錄，包含:
- 訓練時間 (timestamp)
- 運動類型 (站姿抬膝 / 髖部畫圈)
- 完成次數與目標次數
- 訓練時長
- 姿勢合規率
- 動作品質分數

### Q: 可以調整難度嗎
**A:**
目前系統暖身動作的難度是固定的。難度調整方式:
- **增加難度:** 提高目標次數 (例如從 10 次改為 20 次)
- **降低難度:** 降低目標次數，或更頻繁地進行短時間訓練

### Q: 訓練時可以播放背景音樂嗎
**A:**
可以。系統的語音提示和背景音樂不會衝突，您可以使用其他媒體播放器播放背景音樂。

## 訓練建議

### 適合人群
- 物理治療復健患者
- 需要改善髖部靈活性的運動員
- 長期久坐者，需要活動下肢肌群
- 健身愛好者，用於訓練前的動態熱身

### 訓練頻率
- 建議每週進行 **3 ~ 5 次**，每次 10 ~ 15 分鐘
- 可作為正式訓練前的 5 ~ 10 分鐘熱身

### 訓練強度建議
- **初級:** 各運動 5 ~ 10 次，重點放在動作品質
- **中級:** 各運動 10 ~ 15 次，配合訓練速度提升
- **高級:** 各運動 15 ~ 20 次，或連續進行多組

### 安全注意事項
1. **暖身前:** 在開始訓練前，進行 2 ~ 3 分鐘的輕微活動 (步行、臂部旋轉)
2. **停止訓練:** 如感到疼痛 (而非肌肉酸脹感)，應立即停止訓練
3. **醫療建議:** 若有下肢或脊椎相關疾病，請先諮詢醫療專業人士
4. **環境安全:** 確保訓練區域寬敞，無障礙物，防止跌倒

## 技術資訊

### 系統需求
- Windows 10 或更新版本
- 網路攝影機 (USB 或內建)
- Python 3.8+
- 網頁瀏覽器 (Chrome、Firefox、Edge 等)

### 依賴套件
系統已包含以下主要套件:
- **MediaPipe** — AI 姿勢辨識
- **Flask + Flask-SocketIO** — 即時通訊
- **OpenCV** — 影像處理
- **gTTS** — 語音合成

### 資料隱私
- 所有訓練紀錄存檔在本機，不會傳送到雲端
- 攝影機影像僅用於即時動作偵測，不被記錄或儲存

## 故障排查

### 伺服器無法啟動
**症狀:** `Address already in use` 或 `Port 5000 in use`  
**解決方案:**
```bash
# 方案 1: 等待 30 秒後重試 (系統會自動釋放埠口)
# 方案 2: 手動關閉佔用埠口的程序
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

### 瀏覽器連線失敗
**症狀:** `Cannot connect to localhost:5000`  
**解決方案:**
- 確認伺服器終端機沒有出現錯誤訊息
- 手動在瀏覽器網址列輸入 `http://127.0.0.1:5000`
- 嘗試用不同瀏覽器

### 動作偵測卡頓
**症狀:** 即時影像延遲，角度數值不更新  
**解決方案:**
- 關閉其他佔用 CPU 的應用程式
- 移除攝影機前的障礙物
- 檢查攝影機是否有灰塵或鏡頭髒污
